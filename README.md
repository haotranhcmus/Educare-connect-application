# Educare Connect

Hệ thống quản lý giáo dục can thiệp sớm sử dụng Odoo backend và React Native mobile app.

## Modules

- educare_base
- educare_student
- educare_iep
- educare_session
- educare_progress
- educare_reporting
- educare_dashboard
- educare_ai
- educare_mobile_api

## Setup

```bash
pip install -r requirements.txt
```
